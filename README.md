Описание функций
Здесь представлено описание каждой функции, использованной в проекте.

1. Функция report_decorator
Функция report_decorator предназначена для декорирования функций, связанных с созданием отчетов. Она сохраняет результаты выполнения этих функций в JSON-файлы.

Параметры:

filename: Опциональный параметр, определяющий имя файла для сохранения отчета. Если не указан, используется значение по умолчанию из константы DEFAULT_REPORT_FILE.
Возвращаемое значение: 

Обернутая функция, сохраняющая результат в файл.
Пример использования:


@report_decorator("example_report.json")
def example_function():
    # Логика функции
    return {"result": "example"}
Описание логики:
Декоратор перехватывает результат выполнения функции и сохраняет его в JSON-файл с использованием модуля json. При этом ведется логирование процесса сохранения.

2. Функция spending_by_category
Функция spending_by_category рассчитывает общие расходы по указанной категории за последние 90 дней до конечной даты.

Параметры:

transactions_df: DataFrame с транзакциями, содержащими колонки 'date', 'category' и 'amount'.
category: Категория расходов для фильтрации.
end_date_str: Конечная дата для расчета в формате 'YYYY-MM-DD'.
Возвращаемое значение:

Словарь с информацией о категории, периоде и общей сумме расходов.
Пример использования:


data = {'date': ['2023-07-01', '2023-07-15', '2023-08-15', '2023-09-01', '2023-10-01', '2023-10-15'],
        'category': ['Food', 'Transportation', 'Food', 'Entertainment', 'Food', 'Transportation'],
        'amount': [50.0, 30.0, 60.0, 40.0, 70.0, 35.0]}
transactions_df = pd.DataFrame(data)

result = spending_by_category(transactions_df, 'Food', '2023-10-31')
print(result)
Описание логики:
Функция преобразует строки дат в объекты datetime, фильтрует транзакции по дате и категории, суммирует расходы и формирует итоговый отчет.

3. Функция food_spending_report
Функция food_spending_report создает отчет по расходам на еду за последний месяц.

Параметры:

transactions_df: DataFrame с транзакциями, содержащими колонки 'date', 'category' и 'amount'.
Возвращаемое значение:

Словарь с общими расходами на еду за последний месяц.
Пример использования:


data = {'date': ['2023-07-01', '2023-07-15', '2023-08-15', '2023-09-01', '2023-10-01', '2023-10-15'],
        'category': ['Food', 'Transportation', 'Food', 'Entertainment', 'Food', 'Transportation'],
        'amount': [50.0, 30.0, 60.0, 40.0, 70.0, 35.0]}
transactions_df = pd.DataFrame(data)

result = food_spending_report(transactions_df)
print(result)
Описание логики:
Функция вызывает spending_by_category с параметрами, соответствующими категории "Food" и текущей дате, формируя отчет по расходам на еду.
